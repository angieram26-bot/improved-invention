Importar productos de una factura

Carga un PDF de hasta 25 MB o una imagen JPG, PNG o WebP de hasta 15 MB. Para documentos de varias páginas puedes elegir el rango que contiene los productos.

La lectura se realiza en tu navegador. Necesita internet para descargar el lector; el archivo no se envía a un servicio de análisis ni se guarda con la compra.

Hasta 20 páginas por lectura. Si el texto aparece desordenado, prueba Leer todas como imagen. Importar el mismo rango dos veces agrega productos duplicados.

Texto leído o copiado de una factura
La detección básica espera: descripción, cantidad, precio unitario y, si existe, total. Tablas con más columnas necesitan revisión. Nunca se deduce un precio dividiendo un total que podría incluir IVA.

Revisa los productos detectados
